# Techsolvix

Static website. Open `index.html` or serve the extracted folder from a local web server. No build step is needed.

- `index.html` is the homepage. `work/index.html` is the Works listing.
- `homepage-motion.js` and `homepage-motion.css` control homepage motion. `techsolvix.css` contains branding and layout refinements.
- `Techsolvix-Media-Inventory.md` lists the homepage and Works media paths. Replace a file in place to retain its references. Matching names can represent different responsive or page-specific crops.
- Portfolio media and feedback excerpts are inherited reference content. The testimonials are presented as feedback about the featured work. Replace them with your own approved portfolio and testimonials before publication.
- The contact form prepares an email to info@techsolvix.com in the visitor’s mail app.
- The legal pages use the copy from the Techsolvix Terms and Privacy URLs supplied for this build.
